# 🌱 Simple 2D Farming Game

![Godot](https://img.shields.io/badge/Godot-3.3-blue)
![Platform](https://img.shields.io/badge/Platform-PC-lightgrey)
![Status](https://img.shields.io/badge/Status-Learning%20Project-green)

A **very simple 2D farming game** built with **Godot Engine 3.3**.  
This project was made as a small learning project to practice Godot's 2D system, player movement, and simple farming mechanics.

---

## 🎮 Features

- 🚶 Player movement
- 🌱 Basic farming mechanics
- 🗺️ TileMap-based world
- 🧩 Simple interaction system
- ⚡ Lightweight and beginner friendly

---

## 🛠 Built With

- **Godot Engine 3.3**
- **GDScript**
- **TileMaps**
